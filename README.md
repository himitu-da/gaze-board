# 視線入力ボード

スマホのインカメラで使える視線入力ボード。MediaPipe Face Landmarker で顔と虹彩を検出し、9点キャリブレーション後、ボタンを見つめて選択します。

公開URL: https://himitu-da.github.io/gaze-board/

映像は端末内で処理され、外部に送信されません。

## 推定方式
- **自動学習（既定, v1.6〜）**: 起動時に5点（約6秒）見て開始。見つめて選択するたびに、そのボタンの中心を見ていたとみなして選択直前の視線を学習データにする。直後に「⌫」「◀ 戻る」で直された選択は誤選択として学習を取り消す。幾何モデルの注視点と「カメラから目への視線に対する顔の角度」から画面座標へのリッジ回帰（物理的な初期値に向けて正則化）。形は全データで共有し、位置は使用セッションごと＋直近タップで持ち替えに追従。8回・4種類以上のボタンをタップすると見つめての選択がオン。学習データは端末に保存。
- **幾何モデル（既定）**: 顔の姿勢・距離（虹彩径 11.7mm から推定）・眼球回転（半径 12mm）から3Dの視線を作り、画面平面との交点を求め、キャリブレーションでアフィン補正。頭が動いてもずれにくい。
- **回帰**: 目の特徴量から画面座標へのリッジ回帰。調整時の姿勢から頭が動くと大きくずれる。

## 更新履歴
- v1.9.0 端の補正（画面の外側を見続けた方向の感度を徐々に上げる、最大1.6倍、外を見なくなるとゆっくり戻る）。学習の悪循環対策：力んで画面の外を見ていた選択は学習しない、マスの外で選ばれた選択は重みを下げる、端の補正と学習が二重に効かないようにする、曲線の項は画面の範囲外で固定（外を見るほど推定点が内側へ戻る現象の防止）。上下で非対称な縮みの項を追加。
- v1.8.0 目ごとに視線を遠近法どおりに計算（カメラ→虹彩の光線と眼球の交点）し、見えやすい目ほど重く合成。斜めの顔・画面の端寄りの顔でのずれを解消。左右の目の差を学習項に追加（斜視などに対応）、使う目の選択（両目／左目／右目）。文字欄より下では最も近いマスを選ぶ（端のマスに届きやすく）。学習データは新方式で作り直し。
- v1.7.0 自動学習に組み合わせの項を追加（顔の角度×目線、画面内の回転、距離とその×目線）。計測モードに学習した傾きの影響（5°傾ける／5cm遠ざかると何pxずれるか）を表示。
- v1.6.0 文字盤を あかさたなはまやらわ（3列×4段）に変更し定型文を削除。学習をタップから「見つめて選択」に変更（誤選択の取り消しに対応）。起動時に5点の簡単な位置合わせ。
- v1.5.0 タップで自動キャリブレーション（調整なしで開始、電車内でも学習可能）。顔の角度の補正を「カメラから目への視線に対する角度」に変更し、持ち替えに強く。設定に「学習をリセット」。
- v1.4.0 調整を13点（四隅を追加）＋「中央を見たまま顔を動かす」ステップに変更。各点の中央値で当てはめ（端で縮む問題を解消）、顔とスマホの角度によるずれと端での縮みを補正。ブレ対策（頭の姿勢の平滑化、虹彩・目の輪郭の平均、外れ値除去、ブレ補正の強さ4段階、マス判定の余裕、計測モードにブレ表示）。
- v1.2.0 計測モード（顔の角度・距離・眼球回転・注視点、上面図/側面図）、幾何モデルによる推定を追加し既定に。設定パネルを統合。
- v1.1.0 感度・位置・反転の調整、バージョン表示。
- v1.0.0 初版。
